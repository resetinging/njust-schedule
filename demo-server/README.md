# 素材服务器（演示账号 + 种子数据）

用于录制推广视频：在本地跑一个独立后端，小程序连上它即可演示全部核心功能，
**不改动** `wxcloudrun/` 后端源码和 `.miniapp/` 小程序源码。

## 一键启动

```bat
run.bat
```

或手动：

```
..\.venv\Scripts\python.exe app.py
```

启动后监听 `http://127.0.0.1:5000`，使用独立的 `demo.db`（与正式库无关）。

## 小程序连接方式

1. 微信开发者工具打开项目（本地开发拷贝，如 `C:\Users\a\Documents\local\miniprogram`）。
2. `utils/config.js` 里把 `USE_LOCAL` 设为 `true`（指向 `http://127.0.0.1:5000`）。
3. 开发者工具右上角「详情 → 本地设置」勾选 **「不校验合法域名」**。
4. 编译后用演示账号登录：

| 项目 | 值 |
| --- | --- |
| 学号 | `20260001` |
| 密码 | 任意（如 `123456`） |

> 拍完素材后记得把 `USE_LOCAL` 改回 `false`，再传正式环境。

## 演示数据（登录即自动注入，幂等）

- 课表：10 门课覆盖周一~周五，10 种配色自动分配，第 1 周 = 本周，今天列定位正确
- 考试：3 门期末考试（时间/考场/座位号）
- 成绩：本学期 8 门 + 上学期 3 门（多学期对比、GPA 计算）
- 四六级：CET4 / CET6 各一条
- 评教：1 个未完成批次（理论课 第1批），可完整演示「一键评教」进度动画
- 空教室：**真实数据**（走共享服务账号查教务，需网络），可演示「61 间」等结果

## 演示账号特殊行为（不碰教务）

- 所有「刷新」接口直接返回成功，不抓取、不清库
- 评教列表/表单/提交为本地演示数据
- 「清除缓存」对演示账号不生效，种子数据永不丢失

## 重置

删除本目录 `demo.db`，重启即可重新注入。

## 文件

- `app.py` — 入口：设置独立 SQLite 环境变量 → 导入 wxcloudrun 应用 → 注入种子数据 → 替换演示视图 → 启动
- `run.bat` — Windows 一键启动脚本
