## 1. 目标与现状

面向每天查询课表、成绩、空教室和蹭课的大学生，提升扫描效率、排版一致性和触控反馈。第一屏直接提供工具，不增加介绍页和宣传文案。

当前已安装 `tdesign-miniprogram@1.17.0`，继续使用这一组件库。问题来自业务层的分散样式：

- `styles/design-system.wxss` 与 `ui/theme/tokens.js` 部分圆角、间距和动效参数不一致。
- `app.wxss` 与主题文件重复定义按钮、卡片和毛玻璃规则。
- 功能页有无实际作用的装饰圆，图标颜色和实际 PNG 档位不完全对应。
- “我的”页的身份、指标、校历被拆成多个卡片，信息关系不够紧密。
- 课表与子页存在多层入场动画，需防止继承样式再次叠加。
- 既往发生过学期选择器遮挡、长候选列表滑不动、二级页重复进场和底栏闪现，不能回归。

所有判断以当前源码与真实渲染为准；`.tmp` 历史截图仅作补充。旧的 design-style.md 已标记为参考，不能据此恢复紫色渐变或已撤回的立体化样式。

## 2. 调研依据

1. [微信小程序设计指南](https://developers.weixin.qq.com/miniprogram/design/)：重点突出、导航明确、反馈及时、避免误操作、统一稳定。
2. [TDesign 小程序](https://github.com/Tencent/tdesign-miniprogram)：使用现有原生小程序组件体系，避免重复引入其他组件库。
3. [TDesign 自定义主题](https://tdesign.tencent.com/miniprogram/custom-theme)：通过 CSS Variables 覆盖语义 token；自定义 tabBar 必须验证变量作用域。
4. [TDesign Popup](https://github.com/Tencent/tdesign-miniprogram/blob/develop/packages/components/popup/README.md)：弹层由组件管理遮罩和动画，业务内容不得再叠加一次同方向进场。
5. [Apple Motion](https://developer.apple.com/design/human-interface-guidelines/motion)：动效服务于操作反馈，短而准确，方向一致，频繁操作不制造额外等待。

以上网页在规划时已联网读取。TDesign develop 文档可能晚于本地 1.17.0，新增属性必须核对本地包的实际支持情况。

## 3. 视觉规范

### 配色

| 角色 | 目标 | 用法 |
| --- | --- | --- |
| 页面 | `#F6F7F8` | 中性浅灰，避免整页蓝紫染色 |
| 内容面 | `#FFFFFF` | 列表、表单与单个重复项目 |
| 正文 | `#20262D` | 标题、课程名与主要数值 |
| 次级正文 | `#59636F` | 日期、教师、辅助信息 |
| 品牌 | `#3157D5` | 主操作与选中态，保留品牌识别 |
| 成功 | `#247B68` | 已完成、可用、进度 |
| 提醒 | `#A66A0B` | 今天、临近考试、待处理 |
| 错误 | `#B84750` | 失败和危险操作 |

边线使用中性灰；浅色底和弱提示色必须保持可读性。课程维持多色淡底和清晰文字，不把所有课程改为同色。不要仅依靠颜色表达冲突或失败。

### 字体、间距与形状

- 保留现有系统字体/像素字体选择及存储语义，不强制覆盖用户偏好。
- 一般正文 28rpx，次级信息 24rpx，页面标题 36rpx，分组标题 28rpx；紧凑课表单元格可以按领域需要使用更小字号。
- 数值字号只在 GPA、学分等确有必要的位置突出，避免每页都有大数字面板。
- 字距为 0，不用视口宽度缩放字体。
- 间距采用 8rpx 的倍数，页面边距 24rpx，条目间距 12/16rpx，分组间距 24/32rpx。
- 普通卡片圆角不超过 16rpx；控件 12/16rpx，底部弹层 24rpx，胶囊只用于真正的选项或徽标。
- 普通页面分区用留白和分隔线，不将所有分区包成浮动卡片，不做卡片套卡片。
- 去除装饰圆、厚投影、大面积渐变与拟物凸起；毛玻璃仅用于底部导航等少量覆盖层，提供实色回退。
- 图标统一使用项目已有图标入口；不得手工添加零散 SVG、emoji 按钮或引用不存在的 PNG。若改为 TDesign 图标实现，必须保持现有 name/size/color 契约并验证全部别名，不能仅为换图标扩大迁移范围。
- 图标按钮保证约 44px 的有效点击热区并设置清晰的 aria-label。主要导航保留“功能 / 课表 / 我的”文字，不能让图标歧义影响可用性。

### 动效

- 按压反馈约 120ms、轻微缩放到 .98，颜色或明暗提供额外反馈；避免图标旋转、整卡强过冲和强弹跳。
- 主 Tab 切换约 180-220ms，使用轻微超调的 Q 弹曲线，不同时在父层和子组件播放完整入场。
- 二级页面约 240-280ms，统一由现有 tool-layer 管理，淡入并小幅上移后轻微回弹，关闭方向与打开一致。
- TDesign popup 只使用一套过渡，列表长滚动不逐项重播动画，不在滚动中执行反复 setData。
- 动画只变更 transform/opacity 等合适属性，不靠 height/margin 动画推动长列表。
- 保留减少动态效果支持；快速重复开关、切页和关闭过程中不会锁死操作或留下定时器。

## 5. 实施边界

1. 先记录本次改动前的状态，保留两个 Git 工作区的全部既有修改，不能用重置或整目录覆盖实现回退。
2. 前端源在 `.miniapp` 的 `miniapp` 分支，不切换根仓库 `server` 分支；不要改后端、API、登录策略、会话、数据库、广告统计或生产配置。
3. 先统一 `styles/design-system.wxss`、`ui/theme/tokens.js` 与 `app.wxss`，再按页面落地，清理造成冲突的旧规则，不能靠文件末尾不断追加覆盖。
4. `components/generated` 需要核对 DSL/编译器；改生成页面时改源并重新生成，不只改输出；当前生产功能页为 main.wxml，不能误把预览页当成生产页面。
5. 用户在本线程已要求“调研和规划，交给 DSH 执行”，授权实施本方案内的本地改动、相关测试、review 及依既有要求同步；本次不提交、不推送、不发布、不写生产公告。
6. 不读取或输出密码、Cookie、Token。使用模拟数据进行 UI 验收，不能修改生产数据或发真实订阅提醒。

| 问题 | 处理 |

### 7.8 字体偏好修复（review 补充项）

问题：样式统一后，`styles/design-system.wxss` 的默认 `--font-body/--font-display` 被写成系统字，
而 `utils/font.js` 的设计是「pixel 档 = 根节点无 class（走默认变量）」「system 档 = 根节点挂 `.font-system`」，
导致选「像素点阵」时正文字体不变（只有按钮上的 `.font-choice.f-pixel` 预览是像素字）。
另外 `components/settings-view` 的 `font-switching` 类已无对应样式，切换时的淡入淡出也失效。

修复：
- 基座默认改为像素点阵：新增 `--font-pixel: "ZpixPixel", <系统字回退…>`，`--font-body/--font-display` 指向它；
  `--font-num` 保持数字字体不随档位变化；像素字体仍为 `styles/font-pixel.wxss` 的 base64 内联（零网络请求）。
- `app.wxss` 的 `.font-system` 负责覆盖：除 `--font-body/--font-display/--font-num` 外，同时重新赋值
  `--font-plain/--font-ann/--td-font-family/--td-font-family-medium`。原因：自定义属性在 `page` 上声明时
  已把 `var(--font-body)` 替换成像素字面量再继承，只在子树改 `--font-body` 不会回灌，
  否则系统字档下 TDesign 组件仍是像素字（已实测复现并修复）。
- 恢复 `.font-switching` 的轻微短淡入淡出（140ms opacity）：过渡声明放在常驻 `.view-root` 上，临时类只改变透明度，确保加类与移除类时均平滑；并尊重 `prefers-reduced-motion`；
  不加任何父子切页入场动画。
- 新增回归 `tools/test_font_preference.js`：锁定「默认像素 / `.font-system` 覆盖（含派生的 TDesign 令牌）/
  pixel 空 class + system `.font-system` / 页面根节点挂 `fontClass` / `font-switching` 仅过渡 opacity」这些不变量。

真实开发者工具验证（仅内存改 `fontClass`，不写用户偏好，验后还原）：
- pixel 档：`.main-page` / `.feature-title` / `.feature-tile-name` 计算字体均为 `ZpixPixel, …`；
- system 档：同元素为系统字栈，且 **TDesign 按钮（t-class 根节点）也切换为系统字**；
- 两档截图像素级对比可见字形差异（像素档字形点阵化），结束后 `fontClass` 已还原为原值（未写 storage）。
- 截图：`.tmp/shots-font/fontmode-feature-pixel.png`、`fontmode-feature-system.png`、
  `fontmode-profile-pixel.png`、`fontmode-profile-system.png`。
