### 后端

- 新增用户课表/考试/成绩/评教/四六级/培养方案/学籍的每日 00:20 批量同步（启动时补跑）：遍历有持久教务会话的近期活跃用户，限制并发、随机错峰；失败保留旧快照，全部成功才写 `data_cache_at`
- 登录预抓改为“缓存未命中兜底”：当日批量已同步的用户登录不再访问教务，仅首次登录/换学期/无缓存时服务端补抓一次
- 用户主动刷新默认实时访问教务：课表、考试、成绩、四六级、评教、校历、培养方案、学籍和全量刷新均回源最新数据；后台凌晨批量同步仅用于预热快照。`ALLOW_LIVE_REFRESH=0` 仅供运维临时关闭实时刷新
- 空教室查询改为服务端缓存只读：命中快照直接返回；未命中返回准备中提示并由后台补缓存，用户请求不在请求线程访问教务
- 新增配置：`USER_DATA_DAILY_SYNC`、`USER_DATA_SYNC_CONCURRENCY`、`USER_DATA_SYNC_LOOKBACK_DAYS`、`USER_DATA_SYNC_MAX_USERS`、`ALLOW_LIVE_REFRESH`（默认开启，仅用于紧急关闭）；无数据库迁移
- 图书馆 review 修复：严格校验 HTTP200 检索结构（`{}`/null/message/缺字段/类型错误一律报错，`{"total":0,"content":[]}` 仍合法）；非空 `content` 校验 `offset+len<=total`、越界页非空与最后页溢出拒绝，错误结构不覆盖旧缓存
- 图书馆分页契约：`MaxPage` 提高到 200（默认 20 条/页可覆盖真实 2582 条），`has_more` 只在可继续请求时为真；超出上限返回 `truncated/max_page` 并保留真实 `total`，不谎称全部加载
- 图书馆缓存：fresh 与 stale retention 分离（24h 从新鲜期结束起算），每分钟 cleanup 不再误删 stale；`cacheGet` fresh-only 读取保留 retained 项给 stale 回退；共享缓存真正有界 4096（单次扫描优先删 expired、否则 FIFO 淘汰最旧 1 项，替换不增容），空教室/通识等普通缓存维持原过期语义
- 竞赛公告集成：官方 X·Space 页面无可重复访问的机器可读 RSS/API/字段结构，改为管理员维护；扩展 `settings.content_board_v1` 增加 `competitions`（无新表/无迁移），`/api/content-board` 返回启用竞赛并按发布日期倒序，旧 JSON 与 `/api/announcement` 语义不变
- 后台信息中心支持竞赛新增/编辑/删除/启停；服务端校验必填字段、长度、日期和 `source_url` 仅允许 `https` 的 `xspace.njust.edu.cn` / `njust.edu.cn` 子域
- 校园服务前后端（2026-11-24）：新增 `campus_services` 与 `campus_service_leads`，提供公开服务列表/详情、登录用户咨询提交、管理员服务维护与线索跟进；小程序新增合作入口、服务簿、详情与咨询表单；服务上架前强制审核，文案拒绝保过、保上岸、内部名额等承诺
- 校园服务联系方式使用 AES-256-GCM 加密并按服务绑定 AAD，后台列表只显示脱敏值，完整值按需解密；默认保留 30 天并每日 03:30 清理（启动补跑），同一用户/服务/联系方式重复提交去重
- 数据库安全迁移新增 `1002_campus_services`，只创建校园服务表和索引，可从未修改的 `1001_general_education_syllabi` 自动升级
