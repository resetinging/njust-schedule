# 推广视频 · 完整制作流程（从策划到发布）

> 适用范围：课表助手「旧课表下架对比 + 空教室查询 + 一键评教」推广视频
> 配套文件：分镜脚本 `docs/promo-video-script.md`；素材卡 `poster/video/cards.html`
> 工具：手机/PC 录屏 + **剪映**（手机版或专业版均可，本文按剪映命名操作）
> 总耗时参考：**约 3 小时出片**（时间预算见 §8）

---

## 阶段一：前期准备（约 30 分钟）

### 1.1 定目标（先回答三个问题）
| 问题 | 本次答案 |
|---|---|
| 给谁看 | 南理工在校生（有教务账号、用课表类 App 的人群） |
| 发哪 | 抖音 / 视频号 / 小红书（竖屏 9:16）或 B 站（横屏 16:9） |
| 要什么效果 | 让观众知道旧课表下架了 → 我们有空教室 + 一键评教 → 去搜「课表助手」 |

### 1.2 按脚本准备素材清单
对照 `promo-video-script.md` §5 的录屏清单 A~G：

| 素材 | 内容 | 时长建议 |
|---|---|---|
| 录屏 A | 空教室：筛选 → 按楼分组结果 | 8-12s |
| 录屏 B | 空教室：换时段再查 → 定格 61 间 | 6-10s |
| 录屏 C | 一键评教：批量 → 进度走完 | 8-12s |
| 录屏 D | 彩色课表周视图 | 6-8s |
| 录屏 E | 上下课钟点特写 | 5-8s |
| 录屏 F | 自定义课程添加流程 | 8-12s |
| 录屏 G | 公告横幅（可选） | 5s |
| 素材卡 | `cards.html` 5 张（片头/对比/空教室/评教/片尾） | 截图或录屏 |

### 1.3 环境准备（录屏前必做）
- [ ] 手机/模拟器分辨率调到 **1080×1920**（竖版）或 1920×1080（横版）
- [ ] 关闭所有消息通知、勿扰模式
- [ ] 清掉无关缓存数据，提前登录好（避免录到登录过程）
- [ ] 把将要展示的数据准备好（如把当前周停在有课的一天）
- [ ] 录屏方向锁定、亮度拉满、字体显示正常

### 1.4 文案准备
- 旁白：用脚本 §2 的台词（约 45s 版 200 字）
- 配音方案二选一：
  - A：自己录音（手机安静环境，离麦克 15-20cm，正常语速）
  - B：剪映「文本朗读」（选中文本 → 朗读 → 选"轻快男声/知性女声"）

## 阶段二：拍摄 / 录屏（约 40 分钟）

### 2.1 录屏规范
1. 每段多录 **2-3 遍**备用（挑选手指动作最稳的一版）
2. 手指滑动**放慢**，后期可 1.2~1.5 倍变速
3. 每段开头结尾各停 1 秒（留剪辑余量）
4. 关键画面（61 间、进度完成）**定格 2 秒**
5. 出现姓名/学号立即重录或后期打码

### 2.2 素材卡获取
- 浏览器打开 `poster/video/cards.html` → F12 → 设备模拟选 1080×1920
- 卡 1/2/3/5 用**整屏截图**；卡 4（评教进度动画）用**录屏 3-4 秒**

### 2.3 素材命名归档
统一命名：`01_空教室筛选.mp4`、`02_评教进度.mp4`、`card_片头.png`……
一个文件夹装全部，导入剪映时按顺序排。

---

## 阶段三：后期制作（约 90 分钟）

### 3.1 导入与粗剪
1. 剪映 → 新建项目 → 比例选 **9:16**
2. 素材按脚本 §2 镜头顺序拖入时间轴（片头卡 → 痛点 → 对比 → 空教室 → 评教 → 快剪 → 片尾）
3. 每段先粗切：只保留最顺的 3-8 秒，删掉开头结尾停顿

### 3.2 精剪（节奏）
- **0-3s 钩子**：片头卡只留 2.5s，配"下架"重音（whoosh 音效）
- **对比表**：卡 2 录屏里勾选是动画的，保留动画；若用截图，逐行打关键帧做"逐行出现"
- **36-41s 快剪**：四段各 1.2s，卡点切换——先在音频轨道给 BGM **打节拍标记**，让画面切换对齐鼓点
- 变速：录屏段统一 **1.15~1.3 倍**，让操作更干脆；定格帧（61 间）恢复正常速度
- 转场：全部用「叠化/缩放/闪白」轻转场，**别用花哨转场**（学生群体反感）

### 3.3 配音与字幕
1. 先铺配音（自己录或文本朗读），以配音长度定节奏
2. 字幕：文本 → 智能字幕 → 自动识别 → **逐句校对错别字**
3. 字幕样式：白字 + 黑描边 60%，字号 36-42px；关键词（空教室/一键评教/61 间）改主题紫 `#7C6BE8`
4. 字幕位置：画面下 1/3 内，不压手机界面关键区域

### 3.4 音乐与音效
- BGM：音乐库搜「轻快 校园 电子 / vlog 清新」，音量 **-18dB**（以能听清口播为准）
- 音效点：片头"下架"→ whoosh；对比行出现 → "叮"；61 间数字 → "pop"；勾选 → "check"
- 音效音量 -6dB，别盖过人声

### 3.5 调色与统一
- 全片套一个轻滤镜（「鲜亮」或「自然」15-30%），保持录屏与素材卡色温一致
- 素材卡与 App 界面都是紫白主题，**不要再加风格化滤镜**

### 3.6 片头片尾
- 片头用卡 1，片尾用卡 5（停留 ≥3s 方便扫码）
- 片尾二维码：把占位框替换成你的**小程序码**图片

## 阶段四：封面与导出（约 30 分钟）

### 4.1 封面（3:4，平台另传）
- 主视觉：卡 2 对比表 + 大字标题
- 文案：「某课表下架了，用它」/ 「空教室 + 一键评教」
- 规则：大字 ≥ 1/4 画面、颜色用主题紫、不写违禁词（最/第一/唯一）

### 4.2 导出参数
| 项 | 设置 |
|---|---|
| 分辨率 | **1080×1920**（竖）或 1920×1080（横） |
| 帧率 | 30fps |
| 码率 | 推荐/更高（10-16 Mbps） |
| 格式 | MP4 |

## 阶段五：发布前自查清单（5 分钟）

- [ ] 没有出现竞品 App 名称、图标、界面截图（方案 A）
- [ ] 数据类表述有依据（"61 间"标注实测或"以教务为准"）
- [ ] 无姓名/学号泄露，无"最/第一"等违禁词
- [ ] 字幕无错别字，关键词高亮统一
- [ ] BGM 不压口播，音效无爆音
- [ ] 片尾二维码清晰可扫（预览扫码验证一次）
- [ ] 封面与标题一致，无夸大

## 阶段六：发布与运营

### 6.1 发布配置
- 平台：抖音 / 视频号 / 小红书（竖屏）；B 站（横屏长版）
- 标题（参考）：`周三课表下架后，我换了这个课表 App（空教室+一键评教真香）`
- 话题：`#南京理工大学 #课表 #空教室 #评教 #微信小程序 #大学生日常`
- 发布时段：**中午 12:00-13:00 / 晚上 21:00-23:00**（学生活跃高峰）
- 抖音/视频号可关联小程序（挂载"课表助手"）

### 6.2 发布后动作
1. 置顶一条评论引导："微信搜索『课表助手』，空教室查询和评教都在"
2. 转发到班级群/宿舍群/校园墙（熟人冷启动比平台流量更重要）
3. 3 天后看数据（完播率/点赞/转发），**完播率 <25% 就砍开头重剪**，>40% 再投抖+小额测试

## 阶段七：避坑清单（新手高频问题）

| 坑 | 解法 |
|---|---|
| 录屏手指挡住关键内容 | 放慢 + 重录，或后期画中画放大局部 |
| 配音像念稿 | 提前读 2 遍，录 3 遍挑最好的一版 |
| 字幕识别错"评教→评价" | 逐句校对，关键词列表对照 |
| 音乐盖过人声 | BGM -18dB，人声 -3dB，用"人声增强" |
| 转场太土 | 只用叠化/缩放/闪白 |
| 封面文字被平台裁切 | 大字居中留边距，别贴边 |
| 视频审核不过 | 去掉竞品名/图标、去掉"最"字、二维码换小程序码 |
