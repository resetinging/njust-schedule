# 成绩获取流程（独立实现）

## 一、目标

一次性：输入统一身份凭据，输出该生全部历史成绩，跑完退出。

## 二、主干四步

1. **建会话** — 走统一身份认证换取教务会话。智慧理工要求验证码时由后端本地 OCR 识别，失败则回退二维码；凭据验证通过后取得跳转票据，用票据访问教务 SSO 接入点，教务侧下发 Cookie，之后所有请求复用该会话。
2. **取数据** — 优先走教务前端的结构化接口；不可用时降级抓 HTML 表格。请求的地址、方法、头与参数**按实际页面和抓包结果确定，不要凭猜测构造**。
3. **规范化** — 走页面通道时，先读表头行建立"列名 → 列索引"映射，并排除"平均/合计"这类汇总行。
4. **输出** — 序列化后打印或写文件。

## 三、唯一必须处理的判定

**返回空 ≠ 没有成绩。** 三种状态必须分开：

| 状态 | 判定 |
|---|---|
| 有数据 | 正常，解析并输出 |
| 空结果（确实暂无成绩） | 视为**成功**，输出空 |
| 异常（会话失效 / 改版 / 解析不出表） | 视为**失败**，非零退出码 |

把"空"当"失败"，会在没出分时反复排查；把"失败"当"空"，会让人以为成绩丢了。

## 四、输出字段

学年、学期、课程代码、课程名、成绩、学分、绩点、课程属性/性质、考核方式。

只出原始值：成绩里有"优秀/良好"这类非数值记录，也有重修、缓考等特殊情况，在获取层转成数字就再也还原不回来了。
