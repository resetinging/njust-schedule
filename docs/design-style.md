# 小程序设计规范（目标风格 · 参考截图整理）

> 来源: 参考设计截图(课表/成绩/考试/自定义课程/账号 5 页)

## 一、配色系统

| 用途 | 色值 | 说明 |
|---|---|---|
| 主色(紫) | `#7C6BE8` | 品牌色: 按钮/选中/图标/渐变起点 |
| 渐变终点 | `#9B8CF0` → `#A99DF5` | 顶部信息卡/统计大卡/账号卡渐变 |
| 页面背景 | `#F7F6FB` | 淡紫(截图背景) |
| 卡片背景 | `#FFFFFF` | 白色卡片 |
| 卡片边框 | `#EFEBFC` | 淡紫描边(2rpx) |
| 主文字 | `#3A3560` | 深紫灰标题 |
| 次要文字 | `#8A87A8` | 正文辅助 |
| 提示文字 | `#9B96B8` / `#B8B4CC` | 时间戳/占位 |
| 信息行背景 | `#F3F1FA` | 灰底信息行(账号/类型/学期等) |
| **课程块(橙)** | 背景 `#FCF0D9` · 边 `#F3D9A8` · 字 `#8A6116` | 课表课程长条 |
| 成功/勾选 | `#7C6BE8`(实心紫勾) | 四六级勾选框 |
| 警告红 | `#E05A5A` | 退出登录文字 |

## 二、形状与间距

- **卡片圆角**: 20-28rpx（大卡 24-28rpx，小元素 16-20rpx）
- **胶囊圆角**: 999rpx（统计胶囊、按钮）
- **页面边距**: 24rpx 左右
- **卡片间距**: 16-20rpx
- **描边**: 2rpx `#EFEBFC`

## 三、组件规范

### 1. 顶部信息卡（紫色渐变）
```
┌──────────────────────────────────────┐
│ 2026-2027-1            [▦] 第1周 ▼ │ ← 紫渐变圆角大卡
│ 👤 肖尧麓(924101960123)              │
└──────────────────────────────────────┘
```

### 2. 统计胶囊行（成绩页）
`[ 总学分 96.7 ] [ 平均分 78.01 ] [ GPA 2.70 ]`
- 灰底(`#F3F1FA`)紫字(`#7C6BE8`)胶囊，排一行

### 3. 四六级行
紫色实心勾选(✓) + 标题 + 日期右侧 + 「类型 分数 | 折算 xx | 学分 8」副行

### 4. 学期卡片
白色圆角卡：`🎓 2025-2026-2 …… 10门 ⌄`（左侧emoji、标题加粗、右侧门数+折叠箭头）

### 5. 课程块（课表网格）
- 橙黄色圆角长条(`#FCF0D9`)，圆角 8-12rpx
- 第一行: 课程名（加粗，截断）
- 第二行: 教室（小字）
- 底部: 周次（如 "1-13节"，小字）

### 6. 信息行（账号页）
`账号`(左灰字) `924101960123`(右深色字)——灰底(`#F3F1FA`)圆角 16rpx 行

### 7. 按钮
| 类型 | 样式 |
|---|---|
| 主按钮 | 紫渐变/纯紫白字，圆角 999rpx，如「重新同步课表与成绩」 |
| 描边按钮 | 白底紫描边(`#7C6BE8` 1.5px)紫字，如「查看成绩」 |
| 危险按钮 | 白底红描边(`#E05A5A`)红字，如「退出登录」 |
| FAB | 右下角悬浮紫圆角按钮，如「+ 添加课程」 |

### 8. 空状态（卡片式）
```
┌──────────────────────────┐
│         📋(紫色图标)       │
│       暂无考试安排        │ ← 标题加粗
│   2026-2027-1 暂时没有…   │ ← 副文案灰字
└──────────────────────────┘
```

### 9. 页面标题
「返回 + 标题」左对齐（如 `←  成绩查询`），标题深色加粗 34-36rpx
