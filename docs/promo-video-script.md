# 课表助手 · 推广视频分镜脚本

> 主题：与「已下架的旧课表 App」横向对比，主打 **空教室查询** 与 **一键评教**
> 素材卡：`poster/video/cards.html`（9:16 全屏卡片，可截图/录屏直接当镜头）

---

## 0. 先说合规（重要）

直接点名已下架的竞品（含 App 名、图标、界面截图）存在三类风险：**名誉/不正当竞争投诉、平台审核驳回、对方主体追责**。两种处理方式：

| 方案 | 做法 | 适用 |
|---|---|---|
| **A（推荐）** | 不点名：口播/字幕统一用「**某课表 App**」「旧的课表软件」，界面打码或只给灰色图标轮廓 | 抖音/视频号/小红书等公域投放 |
| B | 点名对比，但**只陈述可核实的客观事实**（如"已无法在应用商店下载"），不做贬损性评价，保留证据 | 熟人转发、群内传播 |

脚本正文按 **方案 A** 写；若要改 B，把文案里的「某课表 App」替换即可。
另外：**不要**说"我们的数据更准/教务官方合作"这类无法证实的话；数据（如 61 间空闲）要标注是"实测"。

## 1. 视频规格

| 版本 | 比例/分辨率 | 时长 | 平台 |
|---|---|---|---|
| 主版 | 9:16 · 1080×1920 · 30fps | **45s** | 抖音 / 视频号 / 小红书 / 朋友圈 |
| 长版 | 16:9 · 1920×1080 · 30fps | 90s | B 站 / 知乎 |
| 极简版 | 9:16 | 15s | 信息流广告式快剪 |

- 配音：普通话，语速 ≈ 4.5 字/秒；男声/女声都行，建议"轻快叙述"而不是"带货喊麦"
- 字幕：全片硬字幕。主字幕 36-42px（1080 宽基准）白色 + 细描边或半透明底，位置在画面下 1/3；重点词用主题紫 `#7C6BE8` 高亮
- BGM：剪映音乐库搜「轻快 校园 电子 vlog / 卡点 清新」，音量压到 -18dB 左右，口播为主
- 音效：转场 whoosh、数字出现 "叮"、勾选 "check"
- 片头片尾用素材卡 1 / 卡 5；对比用卡 2；空教室用卡 3；评教用卡 4

## 2. 主版 45s 分镜（9:16）

| # | 时间 | 画面 | 素材/操作 | 字幕（花字） | 旁白 |
|---|---|---|---|---|---|
| 1 | 0-3s | 深紫底，灰色 App 图标被打叉 | 素材卡 1（片头） | **某课表 App 已下架** | 你还在用的那个课表 App，已经下架了。 |
| 2 | 3-8s | 手机录屏：课表能打开但功能停在旧版 | 你 App 课表页缓慢滑动 | 课表还能看<br>空教室、评教呢？ | 课表还能查，但想找间空教室、想把评教点完，还是得自己一个个翻。 |
| 3 | 8-14s | 左右分栏对比表，逐行"叮"出现 | 素材卡 2（对比） | **功能对比** | 换到课表助手，差距是这样的： |
| 4 | 14-20s | 录屏：空教室筛选→结果按教学楼分组 | 【录屏 A】 | 空教室查询<br>校区 / 时段 / 周次 随便选 | 空教室查询——选好校区、时段和周次，全校空闲教室一次列全。 |
| 5 | 20-26s | 录屏：切换不同时段，结果滚动；定格在"61 间" | 【录屏 B】+ 卡 3 数字特写 | **同一时段 61 间空闲**（实测） | 还能按教学楼分组看，离你最近的那栋一目了然。 |
| 6 | 26-32s | 录屏：评教 → 一键批量 → 进度条走完 | 【录屏 C】 | **一键评教** | 评教更省事：批量一键提交，进度实时可见，再也不会漏评。 |
| 7 | 32-36s | 卡 4 的三条勾选动画 | 素材卡 4（评教卡） | 自动识别批次 · 一键提交 · 不漏评 | 一学期的评教，几分钟就能点完。 |
| 8 | 36-41s | 快剪四连：彩色课表 / 上下课钟点 / 自定义课程 / 公告（每个约 1.2s，卡点切换） | 录屏 D/E/F/G | 彩色课表 · 上下课钟点 · 自定义课程 · 公告 | 还有彩色课表、上下课钟点、自定义课程和公告通知。 |
| 9 | 41-45s | 紫渐变片尾 + 二维码 | 素材卡 5（片尾） | **微信搜索：课表助手** | 微信搜索"课表助手"，课表、空教室、评教，一个就够了。 |

**节奏提示**：0-3s 必须抓人（下架悬念）；14-36s 是卖点主体，给足录屏时长；36-41s 快剪提高信息密度；片尾停留 3s 以上方便扫码。

## 3. 长版 90s（16:9）增量内容

在主版结构上补齐：

| 插入点 | 内容 |
|---|---|
| 3-10s | 旧 App 痛点展开：评教要一页页点、空教室要自己比对课表 |
| 14-30s | 空教室加演：切校区（孝陵卫/江阴）、跨大节时段（如第 1-5 节）、结果与"教学楼分组"字幕说明 |
| 30-50s | 一键评教加演：批量弹窗 → 目标分数 → 完成提示；强调"评教截止提醒" |
| 50-70s | 成绩与绩点：GPA 与教务一致、四六级折算、多学期对比 |
| 70-82s | 体验细节：本地缓存秒开、公告即时送达、反馈渠道、隐私说明（数据仅本人可见） |
| 82-90s | 片尾 CTA + 二维码 |

## 5. 录屏清单（照着录，每段 6-12s，1080×1920）

| 编号 | 操作路径 | 要点 |
|---|---|---|
| A | 我的 → 空教室查询 → 选「孝陵卫 / 今天 / 本周 / 第6-7节」 | 结果出来后慢慢下滑，让"按教学楼分组"进画面 |
| B | 同上页，把时段改成「第1-3节」再查一次 | 展示筛选即时生效；停在数字处 2s（画中画叠加卡 3 的 61 间） |
| C | 评教 → 批量评教 → 目标分数 → 开始评教 → 进度走完 | 录到"已完成"提示；进度条动画也可直接用卡 4 录屏 |
| D | 课表页 → 周视图（多点几门不同颜色的课） | 突出多色课程块 |
| E | 课表 → 逐节时间列特写（第X节 上午/下午钟点） | 可后期放大局部 |
| F | 课表 → ＋ → 填一门自定义课程 → 保存 | 展示单双周/周范围选择器 |
| G | 我的 → 公告栏（若有新公告，展示横幅） | 无公告可跳过，或录"设置→第一周日期" |

**录屏技巧**：开发者工具/真机录屏都行，1080×1920、关掉消息通知、提前清空无关数据；录屏时手指移动放慢，方便后期做卡点变速。

## 6. 封面与发布

**封面**：直接用 `poster/video/cards.html` 的卡 2（对比表）+ 大字标题「某课表下架了，用它」；或复用 `poster/index.html` 海报裁成 3:4。

**标题/文案参考**：
- 抖音/视频号：`周三课表下架后，我换了这个课表 App（空教室+一键评教真香）`
- 小红书：`南理工课表助手｜空教室查询+一键评教，比旧课表好用太多`
- B 站：`南理工课表 App 对比实测：旧课表下架之后，我换成了它`

**话题标签**：`#南京理工大学 #课表 #空教室 #期末评教 #微信小程序 #大学生日常`

**发布注意**：
1. 不出现竞品名称/图标（方案 A），避免审核与投诉
2. "61 间空闲"等数据标注"实测，具体以教务为准"
3. 二维码用小程序码，别放个人收款码
4. 若视频里出现同学姓名/学号，打码

---

## 7. 制作顺序（建议 1-2 小时出片）

1. 录 A-G 七段素材（约 30 分钟）
2. 导入剪映 → 按上表摆镜头 → 配音（可用剪映"文本朗读"）→ 加字幕
3. 套 BGM + 音效 → 卡点快剪段（36-41s）对齐节拍
4. 加素材卡作为片头/对比/片尾（截图 or 录屏插入）
5. 导出 1080×1920 / 30fps，检查字幕错别字与合规点
