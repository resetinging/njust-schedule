# 智慧理工密码登录

小程序只收学号 + 智慧理工密码，后端负责换成教务会话，再签发 token 给小程序用。

## 流程

1. 后端直连智慧理工统一身份认证（`ids.njust.edu.cn`）完成登录，拿到票据。
2. 用票据访问教务的 SSO 入口（`bkjw.njust.edu.cn/njlgdx/indexsso.jsp`），
   由 CAS 自动建立教务会话。
3. 从教务页面取出姓名、学号，把会话 cookie 按学号存起来，签发 token 返回。
4. 后续小程序请求带 token，后端用存下来的会话访问教务。

## 几点提示

- 密码不能明文提交，页面 JS 对密码做了 AES 加密，后端要按同样的规则加密。
- 提交登录表单必须带 `service` 参数，否则拿不到票据。
- 登录成功的标志是 cookie 里出现 `CASTGC`，换教务会话靠它。
- 密码默认以 AES-256-GCM 加密落库，用于真实认证后 24 小时内的 Cookie 快速恢复和会话失效时自动重登；退出登录不删除。后台服务账号会复用加密会话 cookie；普通用户仅在本地密码匹配且信任期内复用，否则必须真实验证密码。

## 失败处理

- 需要验证码时用 OCR 识别，识别失败换一张重试。
- 认证失败后短时间内不要再请求，否则账号会被风控冻结。
