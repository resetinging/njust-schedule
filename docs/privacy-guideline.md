## 一、开发者处理的信息

### 1.1 通过微信隐私接口处理的信息

| 信息类型 | 微信接口 | 处理目的 | 触发场景 |
|---|---|---|---|
| 剪切板（仅写入） | `wx.setClipboardData` | 把常用链接地址复制到剪贴板，便于你在浏览器中打开 | 你在「我的 → 常用链接」中**点击某条链接**，或**长按链接后在弹窗中点「复制」**时 |

> **本小程序不读取剪切板**：代码中不存在 `wx.getClipboardData` 等读取调用，复制出去的只有小程序内置的 20 条公开网址。
> 该约束由 `tools/verify_privacy.py` 与 `tools/verify_miniapp.py` 自动检查，出现读取调用即构建失败。

**后台「信息类型」勾选：`剪切板`**，用途文本建议填：

```
开发者使用你的剪切板（仅写入）权限，用于【将小程序内的常用链接地址复制到剪贴板，便于你在浏览器中打开】。
```

> 除剪切板外，**未调用任何其他微信隐私接口**：不获取位置、相册、摄像头、麦克风、通讯录、手机号、微信昵称头像、微信运动、日历、蓝牙、传感器、发票、订单等信息，也没有使用 `wx.getSystemInfoSync`、`wx.getDeviceInfo` 等设备信息接口（详见 §九 代码审计）。

| 信息 | 来源 | 用途 | 保存位置 |
|---|---|---|---|
| 学号 | 你在小程序内主动填写 | 登录学校教务系统；标识数据归属（保证你只看得到自己的数据） | 你的手机本地 + 开发者服务器 |

## 二、开发者如何使用你的信息

1. 仅在实现本指引第一条约定的功能范围内使用，**不会用于用户画像、广告推送、个性化推荐**。
2. 不会将你的学号、成绩、课表等信息用于本小程序功能之外的任何目的。
3. 教务数据由学校教务系统提供，本小程序仅作转发与展示，且**只向你本人展示你自己的数据**（服务端按学号隔离，管理端仅用于故障排查与运维）。
4. 如超出本指引载明的目的或范围使用你的信息，开发者将再次以**页面提示、弹窗等**方式告知并征得你的明示同意。

## 三、第三方插件 / SDK

**本小程序未接入任何第三方插件或 SDK。**

- 未接入微信支付、广告、统计、推送、地图等任何第三方 SDK，也不含任何广告代码。
- 后端服务由开发者自行开发，部署在**微信云托管**（腾讯云）上，腾讯云仅作为基础设施提供方承载数据存储与运算，不将你的个人信息用于其自身目的。
- 除上述外，开发者不会向任何第三方共享、转让或公开披露你的信息，法律法规另有规定或经你另行同意的除外。

| 项目 | 说明 |

### 9.2 非隐私接口（列出以免误判）

| 接口 | 用途 | 为何不属于个人信息处理 |

| `wx.cloud.callContainer` / `wx.request` | 调用开发者自己的后端 | 仅与开发者服务器通信，不采集信息 |

| `wx.downloadFile` / `getFileSystemManager` / `wx.env.USER_DATA_PATH` | 下载并缓存**校历图片** | 下载对象是学校公开的校历图，不涉及用户相册 |

## 十一、附录 C：维护约定（自动化检查）

平台要求「调用情况或个人信息的处理情况发生变动时及时更新本指引」。本仓库用脚本把这件事变成会失败的检查：

```bash
cd .miniapp
python tools/verify_privacy.py
```

脚本会：

1. 扫描全部 `.js` / `.wxml`（先剥离注释，避免注释里的接口名误报），识别代码实际调用的隐私接口；
2. 与本文件顶部的 `<!-- declared-privacy-keys: ... -->` 标记比对；
3. **代码调用了但未声明** → 报错退出（阻断提交，提示同步更新本指引与后台配置）；
4. 声明了但代码未调用 → 告警（多余声明同样有审核风险）；
5. 单独校验「剪切板只写不读」。

改动隐私相关代码时的正确流程：**改代码 → 改本文件（信息类型表 + declared-privacy-keys）→ 更新后台配置 → 提交代码审核**。
