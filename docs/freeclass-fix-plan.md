## 二、当前实现

`wxcloudrun/jwc_client.py:2510-2563` `parse_free_classroom_grid()`：

```python
occupied = any(i < len(cells) and cells[i].get_text(strip=True) for i in target)
if not occupied:
    free.append(name)
```

判定规则是「**目标列全为空文本 → 空闲；任一列有文本 → 占用**」。对 `L/G/K/X/J/◆` 与课程名都正确，但对字面文本 `空闲` **会判成占用**。

## 四、修复计划

### Step 0 —— 零代码，先取真实数据（**必须在改判定规则之前做**）

- 做法：抓一次 `kbxx_classroom_ifr` 的真实响应（本地脚本直连 / 或临时在路由里把 `resp.text` 落盘）
- 统计：**所有单元格文本的 distinct 值 + 出现次数**（含空串、`&nbsp;`、`空闲`、`L/G/K/X/J/◆`、课程名）
- 产出：确定"空闲"的渲染形态 → 决定 Step 1 的判定集合
- 验收：能明确回答「空闲格是空文本还是字面 `空闲`」
- 若发现第三种形态（如 `—`、`.`），一并纳入

### Step 1 —— 解析器状态语义白名单化（P0，对应风险 A）

- 新增常量：`CLASSROOM_CELL_FREE = {"", "空闲", "空", "-", "—"}`（最终以 Step 0 结果为准）
- 判定改为：`文本归一化后 not in FREE_SET` → 占用
- **未知非空文本**：仍判占用，但按值累计计数并打 `warning` 日志（便于发现教务新增状态码）
- 单测（复用 `tests/smoke_test.py` 的 `_grid_html` 夹具，扩展为可注入状态文本）：
  - 覆盖 `空闲 / 空串 / &nbsp; / L / G / K / X / J / ◆ / 课程名 / 未知文本` 共 ≥10 条断言
  - 断言：仅"空闲类"放行；未知文本被排除且触发计数
- 验收：新增断言全绿

### Step 2 —— 区分「解析失败」与「真的没有空闲教室」（对应风险 B、C）

- `parse_free_classroom_grid` 增加结构校验：无 `table` / 行数 < 3 / **目标星期列缺失** / 教室行数为 0 → 抛 `ClassroomGridError`
- `get_free_classrooms` 捕获后设置 `last_error` 并返回 `[]`（保持调用约定）
- 路由 `/api/free-classrooms`：解析失败 → `success:false` + 明确文案（如"教务返回格式异常，请稍后重试"），**不再返回 count:0**
- 前端：走错误分支展示 `errorMsg`，不再显示"该时段没有空闲教室"
- 单测：畸形 HTML（空串 / 仅表头 / 缺星期列 / 无教室行）→ 断言失败路径与错误文案
- 验收：注入畸形 HTML 时接口返回失败而非 0 间

### Step 3 —— 时区统一为北京时间（对应风险 E）

- 新增 `_beijing_today()`（与已有 `_beijing_now()` 同源）
- 替换 `views.py:1346`（默认星期）、`views.py:1099`（教学周推算）、`views.py:1242`（预热日期）
- 单测：固定时刻断言 —— 周日 16:00 UTC（= 周一 00:00 BJT）应得"周一"且周次 +1
- 验收：跨 UTC/BJT 日期边界时"今天"正确

### Step 4 —— 前端三处小修（对应风险 F、G、I）

- **4a** `utils/room-group.js:32`：兼容对象形态 —— `const nm = b && typeof b === 'object' ? (b.name || '') : b`
- **4b** `pages/freeclass/freeclass.js:154`：加递增 `_seq`，回调中比对，丢弃过期响应
- **4c** `pages/freeclass/freeclass.js:35`：缓存键改用**解析后**的 weekday/week（与后端一致），并纳入 semester
- 测试：`tools/test_settings_links.js` 之外新增 `tools/test_freeclass.js`（桩件驱动 `search()`），覆盖 4b/4c
- 验收：连续快速切换筛选，最终列表与筛选器一致

### Step 5 —— 预热与可观测性（对应风险 H、K）

- `views.py:1243`：明天的日期若跨周，则周次用 `本周 + 1`
- 日志补 `xqid`、最终 `xnxqh`、缓存命中/未命中（便于核对 K 的兜底映射是否被走到）
- 验收：周日预热后，周一首次查询命中缓存（日志可见"cache hit"）

### Step 6 —— 确认时段范围语义（对应风险 D，需实测）

- 实测：同一星期分别查「第1-3节」「第11-13节」「第1-13节」，比较教室集合
  - 若「1-3」与「11-13」集合**差异明显** → 教务确实按范围过滤 ✓ 现状正确
  - 若两者**几乎相同** → 教务返回全部列 → 必须改：按列头码过滤（`CLASSROOM_SLOTS` 的 `010203/0405/0607/080910/111213` 映射回目标大节集合取交集）
- 旁证：录屏文案「孝陵卫/今天/本周/第6-7节 → 61 间空闲」量级符合单大节，倾向"教务会过滤"
- 验收：窄范围结果 ⊇ 宽范围结果，且数量符合常识

## 五、执行顺序与依赖

```
Step 0（取真实数据）──► Step 1（判定白名单）──► Step 2（失败可区分）   ← 正确性
                                  │
                                  ├──► Step 3（时区）
                                  └──► Step 4（前端小修）──► Step 5（预热/日志）
Step 6（实测）── 独立，可与 Step 3/4 并行；结论可能反过来影响 Step 1 的目标列选择
```

- Step 0 不完成就不要改 Step 1 的判定集合 —— 否则等于靠猜
- Step 2 是"C 叠加风险"的兜底：即使 Step 1 判断有误，也不会静默给出错误答案

## 六、风险与回滚

| 改动 | 风险 | 控制 |
|---|---|---|
| Step 1 判定集合 | 若把某"占用"状态误判为"空闲" → 报出被占用的教室（**最严重**） | 未知文本一律占用；FREE_SET 只收白名单且以 Step 0 实测为准 |
| Step 2 抛错 | 结构校验过严 → 正常响应被判失败 | 校验只针对"必然异常"的信号（无 table/无教室行/缺星期列），并用真实响应回归 |
| Step 3 时区 | 影响"今天/本周"默认值 | 纯函数化 + 单测固定时刻 |
| Step 4b 竞态 | 序号判断写错 → 正常结果被丢弃 | 桩件测试覆盖"旧响应后到"的场景 |
| Step 6 改列过滤 | 过滤集合算错 → 结果偏大 | 保留开关（环境变量）可回退到"全列"语义 |

所有后端改动均可通过 git revert 单步回滚；`FREE_CLASSROOM_*` 已有环境变量开关的先例（`FREE_CLASSROOM_PREWARM`、`FREE_CLASSROOM_PREWARM_TIMES`），Step 6 建议同样加开关。

### 8.4 新发现

**L. 数据完整性（网格只包含"该周次有排课"的教室）** —— 待决策
- 证据：同一查询下教室行数随周次剧烈变化（第1周 60 → 第6周 129）；且 `jc1=1..13`（该日全天空）空闲为 **0**，若列表包含"整周无课"的教室则必 >0
- 影响：**漏报**整周没排课的教室（不会误报占用），数量可能可观（第3周样本：68 间 vs 第6周 129 间）
- 处置选项：(a) 接受现状并在文案上不承诺"全部教室"；(b) 多周次取并集近似（成本 ×N）；(c) 调研「教室借用」页接口（它按状态列出教室，可能更全，需另做数据源调研）

**M. 网格只填"被请求的那一列"**
- 证据：用 星期3 的响应去解析其它星期，得到"全班空闲"（68/68）—— 其它星期列是空的
- 影响：解析**必须**取请求星期对应的列（现实现正是如此 ✓）；同时说明"样本回归"只能复现该样本所属星期的数字
- 已固化为测试理解，无需改代码
